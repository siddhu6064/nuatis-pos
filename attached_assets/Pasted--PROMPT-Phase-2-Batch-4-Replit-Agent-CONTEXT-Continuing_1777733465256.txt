▶ PROMPT [Phase 2 · Batch 4 · Replit Agent]

CONTEXT
Continuing the throwaway UX prototype for Nuatis POS. Stack: React 18 + Vite + Tailwind v4. Batches 1-3 shipped: Replit Auth, register grid (12 salon services), right-side cart with quantity controls + 8.25% tax + localStorage at `nuatis-pos:cart`, in-place tip selection (No Tip / 15 / 18 / 20 / 25 / Custom), 2-second simulated card reader overlay, success screen with single "New Sale" button, transaction log at `nuatis-pos:transactions` (capped 10).

This batch replaces the single "New Sale" button on the success screen with a four-button receipt picker, and adds a rendered receipt panel that previews exactly what the operator would print/send. All delivery channels are mocked — no real printer, no SendGrid, no Twilio. Tapping any of the four buttons fires a toast confirmation and advances to a final "New Sale" affordance that clears the cart and returns to the register.

GOAL
After mock payment success, operator sees a rendered receipt preview alongside four delivery options [Print, Email, SMS, No Receipt]. Tapping Print fires a "Sent to printer (mock)" toast; Email/SMS reveal an inline input then fire "Sent (mock)" toast; No Receipt advances directly. After any choice, "New Sale" button appears to return to the register.
