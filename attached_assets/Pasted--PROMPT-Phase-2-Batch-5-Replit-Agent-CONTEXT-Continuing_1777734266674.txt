CONTEXT
Continuing the throwaway UX prototype for Nuatis POS. Stack: React 18 + Vite + Tailwind v4. Batches 1-4 shipped: Replit Auth, register grid (12 salon services), right-side cart with quantity controls + 8.25% tax, in-place tip selection, simulated card reader, receipt panel + mock Print/Email/SMS delivery, transaction log at `nuatis-pos:transactions`.

This batch adds customer attach (phone-first lookup, supports post-sale attach) and per-line staff attribution. Mock data only — 6 hardcoded customers, 3 hardcoded staff. The header gains a "Switch Staff" affordance — the active staff drives the default attribution for new cart lines. The iPad represents a shared front-desk device; the active staff is the operator currently ringing, not the device owner.

GOAL
Operator can pick the active staff from header, override staff per cart line, and attach a customer either before checkout (via cart pill) or after the sale (via Receipt screen). Customer attach is phone-first: enter phone, system auto-matches existing customer or offers inline create-new.
