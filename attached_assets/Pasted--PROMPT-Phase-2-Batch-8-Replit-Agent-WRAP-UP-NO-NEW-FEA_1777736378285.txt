   Section: Data Flow — bullet list:
   - Tile tap → useCart.addItem(service, activeStaffId) → state update → localStorage write → render
   - Charge tap → useCheckout transition idle→tip
   - Confirm Charge → useCheckout transition tip→processing → 2000ms setTimeout → processing→receipt
   - Delivery choice → useCheckout.completeDelivery → write to nuatis-pos:transactions → transition receipt→completed
   - New Sale → useCart.clear + useCheckout reset → idle

   Section: Money Math — paragraph + bullets:
   - All amounts are integer cents throughout. No floating-point arithmetic ever.
   - TAX_RATE = 0.0825
   - taxCents = Math.round(subtotalCents × TAX_RATE)
   - tipCents calculated on subtotal only (NOT subtotal + tax)
   - totalCents = subtotal + tax + tip
   - Per-staff revenue = sum of line totals (base + modifier sum) × qty, NO tax/tip allocation

   Section: Why React + Vite Instead of Next.js — short paragraph: Replit Agent workspace did not have Next.js 14 available; switched to Vite without losing UX fidelity. Production migrates to Next.js 14 App Router per locked stack — this prototype is throwaway anyway.

   Section: Why Tailwind v4 Instead of v3 — short paragraph: Replit's default project template installed v4. All utility classes used are v3-compatible; production runs v3.
